# Hostel Hub — Firebase Setup Guide

## Prerequisites
- Flutter SDK installed
- Firebase CLI installed: `npm install -g firebase-tools`
- A Firebase project created at https://console.firebase.google.com

## Step 1: Create Firebase Project
1. Go to https://console.firebase.google.com
2. Click "Add project" → Name it `hostel-hub`
3. Disable Google Analytics (optional)

## Step 2: Enable Authentication
1. In Firebase Console → Authentication → Get Started
2. Enable **Email/Password** sign-in method

## Step 3: Create Firestore Database
1. Firebase Console → Firestore Database → Create database
2. Start in **production mode**
3. Choose a region close to your users

## Step 4: Deploy Firestore Security Rules
```bash
firebase login
firebase init firestore
# Copy contents of firestore.rules when prompted
firebase deploy --only firestore:rules
```

## Step 5: Set Up Admin User
After first user registers, go to Firestore → users collection → find the user document → change `role` from `student` to `admin`.

## Step 6: Configure Flutter with Firebase
```bash
# Install FlutterFire CLI
dart pub global activate flutterfire_cli

# In the project root:
flutterfire configure
```
This auto-generates `lib/firebase_options.dart` with your real config.

## Step 7: Enable Firebase Cloud Messaging (FCM)
1. Firebase Console → Cloud Messaging → Get Started
2. For Android: Download `google-services.json` → place in `android/app/`
3. For iOS: Download `GoogleService-Info.plist` → place in `ios/Runner/`

### Android FCM Setup
Edit `android/app/build.gradle`:
```gradle
apply plugin: 'com.google.gms.google-services'
```

Edit `android/build.gradle`:
```gradle
classpath 'com.google.gms:google-services:4.4.1'
```

## Step 8: Run the App
```bash
cd hostel_hub
flutter pub get
flutter run
```

## Firestore Indexes Required
The following composite indexes must be created in Firebase Console:

### meals collection:
- `userId` (Ascending) + `dateKey` (Ascending)

### complaints collection:
- `userId` (Ascending) + `createdAt` (Descending)

### attendance collection:
- `userId` (Ascending) + `eventId` (Ascending) + `sessionType` (Ascending)

You can create these in Firebase Console → Firestore → Indexes → Composite.
